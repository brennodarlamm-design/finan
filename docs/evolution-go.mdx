# Evolution Go & Upstash Redis

O FinGo utiliza o **Evolution Go** como motor principal de WhatsApp, combinado com **Upstash Redis TLS** para caching e mensageria distribuída.

---

## ⚡ Por que Golang & whatsmeow?

A migração do Baileys (Node.js) para o **Evolution Go (Golang)** proporcionou:

- **Redução de ~90% no Consumo de RAM:** De 500 MB para apenas ~40 MB.
- **Persistência Transacional no PostgreSQL (Neon):** As chaves de sessão são armazenadas no banco relacional (`POSTGRES_AUTH_DB`), evitando desconexões ao reiniciar o container.
- **Eliminação de Erros de Bad MAC:** O `whatsmeow` realiza gerenciamento criptográfico Signal de baixo nível.
